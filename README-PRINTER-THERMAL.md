# Panduan Printer Thermal

Versi ini menggunakan layout teks monospaced yang lebih aman untuk printer thermal 58mm.

## Pengaturan yang disarankan

- Ukuran kertas: 58mm (jangan pilih A4).
- Scale/Skala: 100%.
- Margins/Margin: None/0.
- Header & footer browser: Off.
- Paper source: sesuai printer.
- Jika driver memiliki Density/Darkness, mulai dari nilai normal/medium lalu naikkan satu tingkat bila hasil masih samar.
- Jika ada Speed/Print speed, gunakan normal atau sedikit lebih lambat untuk hasil lebih pekat.
- Gunakan kertas thermal yang masih baru dan sesuai spesifikasi printer.

## Jika hasil masih samar atau putus-putus

Jika seluruh tulisan tetap samar/putus-putus walaupun file preview terlihat jelas, kemungkinan masalah berada pada printer/driver, misalnya:

- thermal head kotor,
- thermal head mulai lemah,
- tekanan head tidak merata,
- kualitas kertas thermal,
- darkness/density driver terlalu rendah,
- print speed terlalu tinggi.

Aplikasi tidak dapat menaikkan panas thermal head secara langsung melalui browser. Setelah software sudah memakai layout teks yang lebih aman, pengaturan printer/driver tetap menentukan ketebalan hasil fisik.
