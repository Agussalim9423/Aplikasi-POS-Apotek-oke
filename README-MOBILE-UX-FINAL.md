# Responsive & Mobile UX Final

Perubahan utama:
- Kasir mobile menggunakan mode **Product First** agar daftar obat mendapat ruang layar lebih besar.
- Tombol **Keranjang** mengambang di bagian bawah layar dengan jumlah item dan total transaksi.
- Keranjang dibuka sebagai **bottom sheet** dengan backdrop dan tombol tutup.
- Area keranjang dapat digulir sendiri dan kontrol sentuh diperbesar.
- Field resep/dokter pada layar kecil ditumpuk menjadi satu kolom.
- Tabel tetap dapat digeser horizontal pada HP/tablet.
- Dukungan safe-area iOS/iPadOS ditambahkan.
- Meta viewport/PWA standalone ditambahkan untuk penggunaan melalui Add to Home Screen.
- Desktop/tablet tidak mengubah layout utama.

Catatan: browser biasa tetap menampilkan address/status bar. Mode fullscreen/standalone maksimal tersedia jika aplikasi ditambahkan ke home screen dan browser/OS mendukungnya.
